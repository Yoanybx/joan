# JOAN Versus Public Ledgers: Comparison Contract v0

JOAN, Bitcoin, Ethereum and XRP Ledger solve different problems. JOAN is not a cryptocurrency or decentralized payment consensus network.

Any comparison must separate:

- local canonicalization and verification latency;
- distributed agreement/finality;
- payment settlement;
- Byzantine/Sybil resistance;
- authority and agent-policy expressiveness;
- audit/recovery evidence;
- fees and externalized infrastructure cost;
- implementation maturity and adoption;
- independent security history.

JOAN can be expected to have lower local latency than global consensus because it does not perform global consensus. That is an architectural scope difference, not proof that JOAN is a superior ledger.

Current result: `NOT RUN`. Bitcoin/Ethereum/XRP Ledger comparison claims are prohibited until workloads, versions, hardware, network conditions, correctness gates, raw outputs and statistical methods are published.
